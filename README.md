# AAM TMS 관제 화면 시안

AAM TMS 내부 관제 화면의 동작 시안임. 모든 기체·절차·판정은 가상 데이터이며, 좌표와 한계값은 임의값임.

- 기본 표시 언어는 영어이며, 상단 KO/EN 또는 주소 `?lang=ko`로 한국어 전환함.
- 화면 역할: `?view=main`(기본), `?view=map`, `?view=detail`, `?view=events`, `?view=flightplan`(운항일정).
- 지도 타일(Esri, CARTO), Leaflet, 웹 글꼴(IBM Plex, 나눔스퀘어)은 외부에서 불러옴.
